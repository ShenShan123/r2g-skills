\section{Experiment 3: Closing Signoff on Failing Designs}
\label{sec:exp3}

This is the main experiment: can an agent turn designs that the fixed open-source flow cannot sign
off into DRC-clean, LVS-matched layouts, and what does \R add over the same model acting alone?

\subsection{Setup}

\paragraph{Designs and baseline.}
The development corpus contains 1{,}249 designs per process kit acquired by rtl-acquire, run on three
open kits: Nangate45 (45\,nm), SkyWater SKY130 (130\,nm, high-density library) and GlobalFoundries
GF180 (180\,nm). Every design is first run once through a \emph{frozen baseline}: the open-source
RTL-to-GDS flow with a fixed per-design specification (clock period, utilisation, die area and power
grid derived by one shared rule) and the platform's full signoff decks. The evaluation scope
(\cref{tab:scope}) is every design whose baseline does not pass both DRC and LVS. Designs whose
baseline ran out of time or memory, or whose checker crashed without a verdict, are excluded from
every arm. The scope was frozen before any arm was evaluated.

\paragraph{Arms.}
Two models of different price classes orchestrate every arm: an inexpensive one (DeepSeek
\texttt{deepseek-flash}) and a frontier one (OpenAI \texttt{gpt-6.1-sol}).
\emph{\R + model}: the model drives the \R agent, whose signoff-loop skill selects and applies repair
recipes. \emph{Model only}: the model receives the failing project, the baseline logs and generic
tools (read/write project files, run the flow from a stage, run signoff, read logs) but no \R code,
recipes or knowledge, under a budget of at most 100 model calls, 10 flow runs, 16 signoff runs and
24\,h wall time. \R arms get the same 24\,h wall budget. \emph{\R + model fallback}: for each design \R
does not close, the model-only agent starts from \R's final project.

\paragraph{What counts as fixed.}
A design is fixed only if full-deck DRC is clean and LVS matches on the same final layout, checked by
the official decks of each kit and verified from the stored reports. The clock period, timing
constraints, process kit, platform files and signoff rules may not change. Physical-implementation
parameters may. An attempt that edits the RTL counts as fixed only if every edited file is proven
equivalent to the original by formal equivalence checking; unproven edits count as not fixed.

\paragraph{Validity rules.}
An attempt killed by the infrastructure (host stall, out-of-disk, checker crash without a verdict)
is voided regardless of its outcome and rerun; every voided attempt is kept with its reason. Each
EDA process is bounded at 64\,GB, and a design that exceeds the bound counts as not fixed.
% TODO(authors): the 64 GB bound was enforced on one of the two execution hosts only (rootless
% container memory limits are ignored on the other); state this or re-check the affected designs.

\paragraph{Same verdicts across models for \R.}
\R's repair pipeline is deterministic given the job the agent submits. We therefore re-ran the
recorded \R + DeepSeek jobs with GPT as the orchestrator in a replay harness that attaches the
recorded pipeline run instead of re-executing it. On all designs, GPT requested exactly the same job
as DeepSeek (0 divergences, 0 early reads of results), so \R + GPT inherits \R + DeepSeek's verdicts
while its model cost is measured directly. On a paired sample with real (non-replayed) runs,
\PH{46/47} verdicts agreed; the one difference was a checker crash.

\paragraph{Cost.}
For every attempt we record model calls, input (uncached and cached) and output tokens, flow runs
and wall time, and price tokens at public list prices: DeepSeek in CNY converted at 7.10\,CNY/USD,
GPT in USD. Calls lacking complete provider usage are re-run, never priced as zero.
