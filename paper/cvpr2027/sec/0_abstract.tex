\begin{abstract}
Large public corpora advance language and vision, but circuit learning lacks graph datasets with
trustworthy physical annotations. Turning public RTL into training examples requires a working
toolchain, qualified sources, successful physical implementation, and correct joins between circuit
entities and measurements. Each handoff can lose designs; misplaced labels or later-stage features can
silently corrupt surviving graphs. We present \R, an evidence-gated workflow, packaged as agent
skills and executed by deterministic programs, that builds graph datasets from public RTL
repositories and measures each handoff.
We evaluate it link by link on three open process kits. (i) An agent installs the complete toolchain
in a clean environment from a dependency checklist, \PH{X/Y components verified, Z tokens}.
(ii) Source qualification yields \PH{N} qualified designs \PH{vs.\ LLM-only baseline}.
(iii) On 676 designs whose frozen open-source baseline fails signoff, \R with an inexpensive model
closes 568 (84\%) to DRC-clean, LVS-matched layouts at \$0.0035 per design, compared with
\PH{DeepSeek-only} and \PH{GPT-only} for the same models acting alone.
(iv) The admitted samples form stage-aware graph datasets whose circuit identity, feature visibility
and physical labels are checked independently, \PH{K checks; learning baselines}.
\end{abstract}
